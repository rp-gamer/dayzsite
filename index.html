■ Passo 1 — Criar conta Supabase (grátis, 2 min)
1. Vai a supabase.com → "Start your project"
2. Cria conta (GitHub ou email)
3. "New project" → dá um nome (ex: pt-boxing)
4. Escolhe uma região → "Create new project"
5. Aguarda ~1 min enquanto cria
■ Passo 2 — Copiar credenciais
No painel Supabase:
⚙ Settings → API
Copia: Project URL e anon public key
■ Passo 3 — Criar tabela
No Supabase → SQL Editor → "New query" → cola e executa:

create table if not exists boxing_state (id text primary key default 'main', data jsonb); insert into boxing_state (id, data) values ('main', '{}') on conflict do nothing;

Depois vai a Database → Replication → activa boxing_state em "Source"
