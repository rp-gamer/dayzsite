■ Passo 1 — Criar Firebase (grátis, 5 min)
1. Vai a firebase.google.com → "Get started"
2. Cria projeto (ex: pt-boxing)
3. No menu → Realtime Database → "Create database"
4. Escolhe localização → começa em test mode
5. Copia a URL (formato: https://pt-boxing-default-rtdb.europe-west1.firebasedatabase.app)
■ Passo 2 — Colar aqui
API Key e Project ID: Firebase Console → ⚙ Definições → Geral → "Your apps" → "Web app" (cria uma se não existir) → firebaseConfig
